# Портфолио: сайты и Telegram-боты для бизнеса в Польше

Одностраничный сайт-портфолио на **Vite + TypeScript** без фреймворка.
Три языка (RU / UA / PL), светлая и тёмная тема, интерактивные демо в макете телефона:
пять мобильных сайтов и четыре Telegram-демо.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранную версию
```

Нужен Node.js 18+.

## Что поменять в первую очередь

1. **`src/config.ts`** — имя, опыт, Telegram, WhatsApp, e-mail, процент за рекомендацию.
2. **`src/content/prices.ts`** — прайс и шаги работы.
3. **`src/i18n/strings.ts`** — все тексты страницы (заголовки, «Обо мне», контакты).
4. **`index.html`** — `<title>`, `meta description` и Open Graph теги.
5. **`src/content/cases.ts`** — описания кейсов рядом с телефоном (задача, что умеет, срок, цена).

## Как устроены демо

Все демо — это объекты, которые `Phone` запускает через `start()` и перерисовывает при кликах.
Клик по элементу с `data-act="..." data-val="..."` внутри телефона вызывает `demo.act(act, val)`.

**Демо-сайт** (`makeSite`): описываете `url`, `logo`, цвета `brand` / `soft`, подвал `foot`,
начальное состояние `initial`, метод `view()` с экранами (`this.scr`: `"home"` и ваши)
и `act()` для своих действий. Переключатель языка внутри сайта (`slang`) и возврат на главную (`home`)
обрабатываются автоматически. Внутри `view()` переводите через `this.S(...)` — это язык демо-сайта,
он не зависит от языка портфолио. Оборачивайте разметку в `this.shell(...)`.

**Мини-приложение** (`makeScreens("app", …)`): те же `view()` / `act()` / `this.go(screen)`,
кнопки снизу возвращаются в `actions`.

**Чат-бот** (`makeChat`): граф узлов. У каждого узла `bot(state)` — сообщения бота,
`buttons(state)` — кнопки с `next` (следующий узел) и `set` (что записать в состояние).

### Добавить новый демо-сайт

1. Скопируйте `src/demos/sites/cleaning.ts` в новый файл и поменяйте контент.
2. Добавьте объект в `SITE_CASES` в `src/content/cases.ts` (эмодзи, название, задача, фичи, срок, цена).
3. Всё. Вкладка появится автоматически.

## Деплой

Сборка — статичные файлы в `dist/`. Подходит любой статический хостинг:
Vercel, Netlify, Cloudflare Pages, GitHub Pages. Build command `npm run build`, output `dist`.

## Что стоит сделать дальше

- **Свои шрифты.** Сейчас Onest и Unbounded грузятся с Google Fonts. Для сайта в ЕС
  лучше раздавать их со своего домена (RODO / GDPR) — например через `@fontsource/onest`
  и `@fontsource/unbounded`.
- **Политика конфиденциальности.** Если добавите аналитику или форму, нужна `polityka prywatności`
  и баннер cookies. Сейчас сайт хранит только выбранный язык в `localStorage`.
- **SEO по языкам.** Язык переключается на клиенте, поэтому Google проиндексирует в основном
  первую версию. Если важен поиск на трёх языках, следующий шаг — отдельные URL `/pl`, `/uk`, `/ru`
  с `hreflang` (удобно сделать на Astro, данные и демо переносятся почти без изменений).
- **OG-картинка** 1200×630 для превью ссылки в Telegram и Facebook.
- **Аналитика** (Plausible / Umami — без cookies) и цели на клики по кнопкам Telegram / WhatsApp.
- **Реальные кейсы.** Демо помечены в подвале как прототипы. Когда появятся настоящие проекты,
  добавляйте их отдельной вкладкой или заменяйте демо.
- **Вычитка.** Польские и украинские тексты стоит один раз показать носителю языка.
